This roadmap focuses on preparing TeacherMarket as a reusable open-source core for teacher communities.

- [x] Prepare public README.
- [x] Add license.
- [x] Add contributing guide.
- [x] Add security policy.

- [ ] Add monitoring and structured logging guide.

- [ ] Prepare first issues labeled `good first issue`.
- [ ] Prepare maintainer workflow with Codex / AI-assisted review.
